# Template - Clínica de Estética

## Objetivo
Automatizar o primeiro atendimento de clínicas de estética.

## Funcionalidades
- Recepção automática.
- Apresentação de procedimentos.
- Qualificação de contatos.
- Solicitação de agendamento.
- Transferência para atendente.

## Personalização
- Nome da clínica.
- Serviços.
- Horários.
- Endereço.
- Links.
- Informações comerciais.
